## Current architecture

- Next.js 16 / React 19 / TypeScript command center calls FastAPI only through a same-origin, allowlisted server proxy.
- FastAPI owns validation, the simulator, clinical engines, document gateway, audit events and persistence. No LLM or external model API is used.
- SQLAlchemy uses SQLite for the credential-free local demo and PostgreSQL JSONB for a dedicated Supabase deployment.
- The default two-second tick represents one simulated clinical minute. Reset creates a new run while preserving prior records and originals.
- One backend worker owns rolling state and metrics. Database checkpoints restore the active run after restart.

## Clinical and metric decisions

- Published adult NEWS2 arithmetic uses SpO₂ Scale 1 only. NEWS2 ≥7 is immediately CRITICAL; NEWS2 5–6 or any component scoring 3 is immediately at least WARNING. Persistence never delays these triggers.
- Patient-specific signals use a 30-observation rolling median, scaled MAD, timestamped slope and three-sample persistence for lower-risk experimental candidates. Five lower candidates are required for recovery.
- Explanations are templates over typed NEWS2 components, baselines, deviations and trends. VITALIS does not diagnose or recommend treatment.
- Naive alerts count each violating parameter on each sample. VITALIS alerts count upward attention transitions on the identical stream. Reduction and episode metrics are computed for each run and labelled as synthetic scenario evidence.

## Security model

- Originals are written once under UUID paths, hashed with SHA-256 and never rewritten during scanning or reset.
- The gateway accepts PDF/UTF-8 text only, checks PDF signatures, enforces a 5 MB body limit and runs parsing in a secret-free subprocess with time, page, text and object limits. Linux containers also apply CPU/memory limits.
- Hidden/tiny/off-page content, annotations, attachments, active actions, invisible Unicode, encoded text and AI-directed manipulation patterns produce structured signals. Parser failures fail closed.
- Raw text remains an untrusted table. Only exact-schema numeric facts from passed scans enter the historical context channel, with page/line provenance and an unverified label. Document prose has no call path into NEWS2, state transitions or acknowledgement.
- Local demo access is loopback-only. Hosted mode requires a server-side API bearer token and frontend access password. The proxy rejects cross-site mutations and only forwards allowlisted API paths.
- PostgreSQL tables enable RLS and revoke `anon`/`authenticated` access; the browser receives no Supabase credential.
